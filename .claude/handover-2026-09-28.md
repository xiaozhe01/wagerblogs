## 4. Three defects these passes uncovered

Recorded because each was invisible and each has a reusable shape.

**`<time>` had never rendered on any story or article.** `ArticleByline`
guarded with `/^\d{4}-\d{2}-\d{2}/`, but the route passed it `formatDate`'s
output — `"Sep 27, 2026"` — so the guard failed every time. The guard was right;
its input was not. `PublishMeta` now takes the raw record value and formats
internally.

**The focal point was stored but never read.** Payload has always written
`focalX`/`focalY` and crops its own derivatives around them. The frontend set no
`object-position`, so every `object-cover` image centred regardless of what the
editor picked. Never new work — only the frontend half was missing.

**`crumb` was added optional and therefore did nothing.** `Verticals.crumb` is
`required: true`, which is why `/reviews/sportsbooks` always read "Sportsbooks".
The same field on News and Articles was made optional so thirteen existing
records would not fail validation — and optional plus NULL falls straight
through to the title. The fix was the fallback, not the field.

## 5. Things that will bite you

**Config and migration must land in the same commit.** Two outages on
2026-09-26/27 came from adding a Payload field without running its migration in
the same step: the Drizzle schema changes as soon as the config does, so every
query then selects a column that does not exist (`errorMissingColumn`, 42703).

**`payload.find` with `overrideAccess: false` and no `user` sees only
published.** Always **spread** `publishedFilter`, never destructure it —
destructuring silently drops `user` and every detail route 404s in preview.
`tests/draft-auth-propagation.test.ts` guards this.

**Payload config changes need a dev restart.** No hot reload. A stale server
once made a correct fix look broken for several minutes.

**`withoutEnlargement` has three states, not two.** For an imageSize:
`undefined` omits the derivative entirely when the source is smaller than the
target, `true` returns the source uncropped at its own aspect ratio, and only
`false` crops and scales to the real dimensions. Measured, not inferred.

**Payload builds derivatives at upload time only.** Adding an `imageSize` does
nothing for existing records. `scripts/regenerate-media-sizes.ts` backfills;
it passes `overwriteExistingFiles`, without which an update collides with the
record's own file and Payload appends `-1` to the filename.

**Next replaces `openGraph` wholesale rather than merging with the layout's.**
Anything the layout sets is lost on any route emitting its own — which is why
`lib/og.ts` restates `type`, `siteName` and the image fallback. The same trap
applies to `twitter`: `buildTwitter` sets `card` and nothing else, because a
title or image declared sitewide would override every route.

**Prettier has no config file.** Always pass `--print-width 100`; a bare
`npx prettier --write` reflows the whole repo at 80.

**Seeds are not idempotent.** `npm run seed` / `seed:content` key "already
exists" on slug or name. Never run them against a hand-edited database — a
verification run on 2026-09-24 created seven duplicates, six of which are still
in the database.
